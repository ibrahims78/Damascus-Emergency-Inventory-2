# ملاحظات الإصدار 4.0.2 — تحديث الهوية البصرية

## التحديثات

- استبدال الشعار الرئيسي بشعار **مديرية صحة دمشق / Damascus Health Directorate** المرفق والمعتمد.
- توحيد الشعار في شاشة الدخول، الشريط الجانبي، صفحات الخطأ، التقارير المطبوعة وسندات العمليات.
- تحديث favicon وأيقونة الويب.
- تحديث أيقونات التشغيل وشاشة البدء لنسخة Android.
- تحديث شعار نافذة نسخة Windows المعبأة.
- رفع إصدار التطبيق إلى `4.0.2` و`versionCode=402`.

## ملاحظات البناء

- تبنى نسخة Android من خلال:
  `release-artifacts/v4.0.2/android/build-android-apk.ps1`
- تبنى نسخة Windows من خلال:
  `release-artifacts/v4.0.2/scripts/reassemble-electron.mjs`
- ملفات APK وWindows النهائية تُنشأ بعد توفير حزمة البناء والتوقيع الخاصة بالمنصة.
