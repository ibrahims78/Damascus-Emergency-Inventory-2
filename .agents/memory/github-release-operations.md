---
name: إدارة GitHub Releases
description: ملاحظة تشغيلية حول تنفيذ عمليات أصول GitHub Releases بأمان داخل مساحة العمل
---

عند تنفيذ عمليات GitHub Releases، إذا بقي طلب السر داخل sandbox في حالة انتظار رغم تأكيده، يمكن استخدام متغير البيئة المخصص في أمر تشغيل غير تفاعلي، مع عدم طباعة قيمته مطلقًا. يجب قراءة الإصدارات والأصول أولًا، تنفيذ الحذف بالمعرّفات الدقيقة، ثم إعادة القراءة والتحقق من النتيجة.

**Why:** واجهة جلب الأسرار قد لا تعيد القيمة فور تأكيد المستخدم، بينما قد يكون السر متاحًا للعمليات المصرح بها في بيئة التشغيل.

**How to apply:** استخدم هذه الطريقة فقط لتنفيذ العملية المطلوبة، أخفِ قيمة السر، ولا تحذف أي أصل قبل مطابقة اسم الإصدار والأصل المطلوبين والتحقق النهائي.
