- [تهيئة Git في مساحة العمل](git-bootstrap.md) — عند وجود ملفات Replit المخفية، اربط remote من داخل المساحة بدل clone إلى مجلد غير فارغ.

- [مصادقة GitHub للرفع](github-git-auth.md) — استخدم PAT من الأسرار عبر Basic helper مؤقت؛ لا تضع التوكن في remote أو تطبعه.

- [بوابة المواد والدفعات](inventory-phase0-phase2.md) — فحوص خط الأساس المعزولة في Desktop تحتاج إزالة DATABASE_URL الموروث قبل تشغيلها.
- [حدود معاملات PGlite](pglite-transaction-connection.md) — لا تستخدم اتصال قاعدة البيانات العام داخل معاملة PGlite؛ قد يعلق الطلب حتى انتهاء مهلة fetch.
- [ترحيل هوية المنتج](branding-migration.md) — غيّر الهوية المرئية إلى مستودعات المديرية مع إبقاء معرفات أندرويد والترخيص وقيم البيانات القديمة للتوافق.
- [حزم تفعيل المورّد](vendor-activation-kit.md) — الحزمة العامة لا تحتوي مفتاح التوقيع؛ إصدار المورّد المنفصل فقط يشغّل مولدات التراخيص ولا يُرفع إلى GitHub.
