---
name: تشغيل المشروع بعد الاستنساخ
description: قيد تشغيل خاص بالنسخة المستنسخة حديثاً من مشروع مستودع الإسعاف.
---

بعد استنساخ المشروع، قد لا يكون `node_modules` موجوداً رغم وجود lockfile؛ تشغيل workflow قبل تثبيت التبعيات يؤدي إلى فشل أوامر Vite وesbuild.

**Why:** بيئة العمل لا تثبت تبعيات المستودع تلقائياً عند الاستنساخ، بينما workflow يفترض توفرها.

**How to apply:** نفّذ تثبيتاً مطابقاً للـlockfile (`pnpm install --frozen-lockfile`) قبل أول تشغيل أو فحص build بعد استنساخ/إعادة إنشاء مساحة العمل.
