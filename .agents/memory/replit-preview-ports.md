---

في المشاريع التي تفصل API والواجهة إلى Workflows مستقلة، قد لا يكون منفذ المعاينة
الافتراضي 5000 هو منفذ الواجهة. يجب قراءة منافذ Workflows ثم استخدام المنفذ الفعلي
في فحص Screenshot/HTTP؛ فشل 5000 لا يعني أن التطبيق متوقف.

**Why:** بيئة Replit الحالية تشغّل API والواجهة على منفذين مختلفين، ولقطة المنفذ
الخطأ أعطت اتصالاً مرفوضاً رغم أن الخدمتين كانتا تعملان.

**How to apply:** بعد كل تغيير، أعد تشغيل Workflow المتأثر، افحص سجله، ثم استخدم
Screenshot على منفذ الواجهة المعلن وhealth check على منفذ API.
