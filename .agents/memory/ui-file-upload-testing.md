---
name: اختبار رفع الملفات
description: ملاحظة مستقرة عند اختبار حوار استيراد ملفات المواد في المتصفح
---

عند اختبار حوار استيراد المواد آلياً، حالات الامتداد أو الحجم غير المدعوم تخفي عنصر اختيار الملف وتعرض زر «إعادة المحاولة». يجب الضغط على إعادة المحاولة وانتظار ظهور عنصر input جديد قبل اختيار الملف التالي.

**Why:** الاحتفاظ بمعرّف عنصر input السابق بعد تغيير حالة الحوار يجعل أدوات المتصفح تفشل رغم أن مسار التطبيق نفسه يعمل.

**How to apply:** أعد اكتشاف عنصر اختيار الملف بعد كل حالة خطأ، واختبر الملف الصالح في جلسة منفصلة أو بعد إعادة المحاولة.
