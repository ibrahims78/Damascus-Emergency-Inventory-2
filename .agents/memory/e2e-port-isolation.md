---
name: عزل اختبارات E2E
description: قيد بيئي مهم عند تشغيل اختبارات الخادم المحلية بجانب workflow التطبيق.
---

يجب أن تستخدم اختبارات E2E منافذ مستقلة وقابلة للضبط، بما فيها منفذ منفصل
لاختبار البذر العشوائي، وألا تفترض أن المنفذ 8080 متاح.

**لماذا:** workflow الرئيسي يشغّل API على 8080؛ استخدام المنفذ نفسه قد يجعل
فحص الصحة ينجح من الخادم الرئيسي بينما تكون عملية الاختبار الفعلية متوقفة أو
غير مهيأة.

**كيفية التطبيق:** مرّر عناوين العقد إلى اختبارات المزامنة والأمان عبر متغيرات
البيئة، وأنشئ مجلدات بيانات مؤقتة لكل عقدة، ثم احذفها بعد الاختبار.
