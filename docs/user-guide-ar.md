# دليل المستخدم العربي

## الدخول والأدوار

بعد إنشاء حساب المدير الأول، يدخل المستخدم باسم المستخدم وكلمة المرور. الأدوار:

- **مدير:** جميع العمليات، إدارة المستخدمين والإعدادات والنسخ الاحتياطي.
- **مسؤول مستودع:** المواد والتجهيزات والحركات والتقارير التشغيلية.
- **مشاهد:** قراءة التقارير والبيانات دون إنشاء أو تعديل حركات أو تصنيفات.

## إدارة المخزون

1. أضف المادة أو التجهيز مع الوحدة والحد الأدنى والموقع.
2. استخدم **إدخال** لتسجيل مذكرة التسليم وتاريخها والدفعة والصلاحية.
3. استخدم **إخراج** للمواد الاستهلاكية مع الجهة والسبب والوجهة.
4. يستخدم النظام FEFO تلقائياً للدفعات ذات الصلاحية، ويتجاهل الدفعات المنتهية.
5. استخدم **التسوية** فقط لتصحيح فرق موثق، مع إدخال السبب.

## العهدة والتلف والمرتجع

- **تسليم عهدة:** يربط التجهيز بصاحب العهدة والمذكرة والمكان ولا ينقص إجمالي
  التجهيز.
- **إعادة عهدة:** تسمح بإعادة كلية أو جزئية، وتطلب حالة الإعادة.
- **تسجيل تلف:** يسجل السبب والتاريخ ويؤثر في الرصيد التشغيلي حسب نوع التجهيز.
- **مرتجع مركزي:** حركة مستقلة إلى المستودعات المركزية وليست إعادة للعهدة.

## التقارير والطباعة

من صفحة **التقارير** تتوفر:

- الجرد العام والحركة والانتهاء والمواد تحت الحد والتجهيزات.
- **الوضع التفصيلي:** المتاح، العهدة، التالف، والدفعات.
- **العهد المفتوحة:** البحث، الحالة، مدة التأخر، والكمية المتبقية.

يمكن طباعة التقرير أو تصديره إلى Excel. من سجل العمليات افتح رقم السند لطباعة
سند A4؛ يوضح السند نوع الحركة، الدفعة، العهدة، الإعادة، التلف، المرتجع أو
التسوية والسبب والملاحظات بحسب الحالة.

## التنبيهات والتدقيق

يعرض الجرس التنبيهات المتعلقة بالحد الأدنى والانتهاء وحالة التجهيز. يعرض
سجل التدقيق للمدير إجراءات الدخول والإضافة والتعديل والحذف والحركات الناجحة
والفاشلة والنسخ الاحتياطية.

## قواعد السلامة

- لا تستخدم حساباً مشتركاً.
- لا تشارك كلمة المرور أو `SESSION_SECRET`.
- راجع السند قبل الطباعة، واحفظ رقم المذكرة والسبب في كل حركة.
- أبلغ مسؤول النظام عن أي فرق بين التقرير والرصيد الفعلي قبل إجراء تسوية.
