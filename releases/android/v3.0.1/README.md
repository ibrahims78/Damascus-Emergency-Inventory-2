# Damascus Emergency Inventory — Android Offline `3.0.1`

حزمة Android Offline مبنية من آخر commit في الفرع `main`.

## المحتوى

- `damascus-emergency-inventory-offline-v3.0.1.apk` — حزمة Android Release.
- `SHA256SUMS` — مجموع SHA-256 للتحقق من سلامة الملف.

## التثبيت

1. نزّل ملف APK إلى جهاز Android.
2. فعّل السماح بتثبيت التطبيقات من هذا المصدر عند الطلب.
3. ثبّت التطبيق وافتحه.

تعمل هذه النسخة محليًا باستخدام IndexedDB داخل الجهاز، ولا تحتاج إلى API أو PostgreSQL أو اتصال خارجي أثناء التشغيل غير المتصل.
