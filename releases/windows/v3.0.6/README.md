# Damascus Emergency Inventory Desktop — Version 3.0.6

هذه حزمة Windows Portable مستقلة مبنية من الحالة الحالية للفرع `main` بعد
إصلاح مشكلة تعليق حفظ صفحة إعادة العهدة في إصدار Windows السابق. تتضمن مجلد
التشغيل الكامل لـ Electron وواجهة الويب وخادم API المحلي وقاعدة PGlite؛ ولا
تحتاج PostgreSQL أو خادماً خارجياً للتشغيل المعتاد.

## التشغيل

1. فك ضغط `Damascus-Emergency-Inventory-v3.0.6-Windows.zip` على جهاز Windows x64.
2. افتح مجلد `Damascus Emergency Inventory 3.0.6`.
3. شغّل ملف `Damascus Emergency Inventory.exe`.

## الإصلاحات المتضمنة

- تضمين آخر كود مصدر بدل حزمة v3.0.5 القديمة المبنية من commit سابق.
- تثبيت دورة حياة معاملات IndexedDB وإغلاق الاتصالات القديمة وإعادة المحاولة
  بعد فشل تهيئة قاعدة البيانات.
- إكمال دورة إعادة العهدة: تسجيل الحركة وتحديث العهدة المفتوحة وتحديث حالتها
  ومنع تعليق زر الحفظ.
- حفظ وتحديث حالات الإعادة المخصصة بشكل آمن داخل معاملة الحركة.

## التحقق

- الإصدار: `3.0.6`
- Windows x64 Portable.
- قيمة SHA-256 موجودة في `SHA256SUMS`.
- تم اجتياز فحص TypeScript وبناء الواجهة وAPI قبل إنشاء الحزمة.
